# Module 1 - Machine learning foundations for Generative AI

## Learning objectives

- Explain what a machine-learning model actually learns.
- Distinguish parameters from hyperparameters.
- Distinguish training from inference.
- Identify supervised, unsupervised, self-supervised, and reinforcement learning.
- Explain why LLM pretraining is primarily self-supervised learning.
- Understand features, labels, targets, samples, and datasets.
- Explain train, validation, and test sets.
- Identify underfitting and overfitting.
- Explain generalization.
- Understand the bias–variance trade-off.
- Recognize data leakage.
- Distinguish a loss function from an evaluation metric.
- Understand preprocessing and feature engineering.
- Explain where classical ML concepts appear in modern LLM systems.

### What is machine learning 

*Def 1:*

Machine learning is a subfield of artifical intelligence that uses algorithms trained on **datasets** to create models capable of performing tasks that would otherwise only be possible for humans.
